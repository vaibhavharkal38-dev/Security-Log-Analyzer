# Security Log Analyzer – Mini SOC Dashboard

A Python Flask-based web application that analyzes security log files, detects failed login attempts, identifies suspicious IP addresses, and displays security events through a web dashboard.

## Features
- Analyze log files
- Count failed login attempts
- Identify suspicious IP addresses
- Visualize failed logins using Chart.js
- Monitor newly appended log entries
- Display live security alerts

## Technologies
- Python
- Flask
- HTML, CSS, JavaScript
- Chart.js

## How to Run

Run this command from the project folder:

.\venv\Scripts\python.exe app.py

Then open http://127.0.0.1:5000 in your browser.
